# 바이올린 마스터 (VIOLIN MASTER)

악보·튜너·메트로놈·녹음을 한 저장소에 담은 시리즈 앱이에요. 모두 기기 안(브라우저)에 저장하고, 서버나 구글 연결이 필요 없어요. 브랜드 규칙은 `../brand/BRAND.md`에 있어요.

| 폴더 | 앱 | 하는 일 |
|---|---|---|
| `/` (`index.html`) | 첫 화면 | 앱 타일 4개, 최근 본 악보 |
| `score/` | 악보 | 악보 모으기·보기·보잉 적기. 곡마다 템포(BPM)·박자 저장, 보기 화면 아래 **♩ 템포** 단추로 바로 째깍(길게 누르면 메트로놈 앱), **튜너** 단추 |
| `tuner/` | 튜너 | 마이크로 음 인식, 바늘(±50 cent), G·D·A·E 기준음 소리, 기준음 A4 430~450 Hz |
| `record/` | 녹음 | 곡을 골라 녹음(최대 30분), 날짜별 목록, 다시 듣기(0.5~1.25배), 음정 그래프와 자주 벗어난 음, 이름·곡 바꾸기, 내려받기, 파일 불러오기. 악보 보기 화면의 **녹음** 단추로 그 곡을 바로 녹음 |
| `tempo/` | 메트로놈 | 30~240 BPM, 다이얼 밀기·탭 템포, 박자 2/4~6/8, 박 점 눌러 강세(강·보통·쉼), 세분, 소리 3가지, 템포 올리기 연습, 저장한 템포 |

## 올리는 방법 (GitHub Pages)

1. GitHub에서 **+ → New repository**로 `violin-master` 저장소를 만들어요 (Public).
2. **Add file → Upload files**에 이 폴더 안의 것을 **폴더째** 모두 끌어다 놓아요: `index.html`, `backup.js`, `sw.js`, `manifest.webmanifest`, `icons`, `score`, `tuner`, `tempo`, `record`. **Commit changes**.
3. **Settings → Pages**에서 Branch를 **main / (root)**로 저장해요.
4. 1~2분 뒤 `https://내아이디.github.io/violin-master/` 가 열려요.

- 홈 화면에 추가할 때: 첫 화면을 추가하면 "바이올린 마스터" 하나로 모든 앱을 쓰고, 각 앱 주소(`…/score/`, `…/tuner/`, `…/tempo/`, `…/record/`)를 따로 추가하면 앱마다 아이콘이 생겨요. 둘 다 해도 괜찮아요.

## 백업과 복원, 아이패드에서 쓰기

- 첫 화면 **백업과 복원**: 악보·보잉·세트리스트·곡 템포·녹음·설정을 파일 하나(`.vmbackup`)로 묶어요. 아이폰·아이패드에서는 **아이클라우드에 저장 → 파일에 저장 → iCloud Drive**로 두면 돼요.
- 다른 기기에서는 첫 화면 **백업 불러오기**로 그 파일을 골라요. 이미 있는 악보·녹음은 그대로 두고 없는 것만 더해요. 예전 악보 앱의 `.json` 백업도 받아요.
- 아이패드에서는 첫 화면을 사파리에서 열고 **공유 → 홈 화면에 추가**를 한 뒤 그 아이콘으로 써요. 아이콘은 첫 화면 하나만 추가하는 걸 권해요(네 앱이 한 창에서 같은 저장소를 써요).
- 홈 화면 앱은 사파리와 저장소가 따로예요. 사파리에서 쓰던 게 있으면 사파리에서 백업 → 홈 화면 앱에서 불러오기.
- 자동 동기화는 아니에요. 기기를 바꿔 쓸 때마다 백업 → 불러오기를 해요.
- `backup.js`를 고치면 첫 화면 `sw.js`의 `VERSION`을 올려요.

## 이미 쓰던 악보는 그대로예요

예전 `violin-sheets` 저장소와 새 `violin-master`는 둘 다 `내아이디.github.io` 주소라서 기기 저장소를 함께 써요. 새 악보 앱을 열면 넣어 둔 악보와 보잉이 그대로 보여요. 옮긴 걸 확인한 뒤 예전 저장소는 지워도 돼요. (다른 기기·브라우저로 옮길 때는 전처럼 백업 파일을 써요.)

## 고칠 때

- 각 폴더의 `index.html`은 인터넷이 될 때 열면 새 버전으로 바뀌어요. 아이콘이나 `sw.js`를 고쳤으면 그 폴더 `sw.js` 맨 위 `VERSION` 끝 숫자를 하나 올려요.
- 앱끼리 주고받는 것: 악보 앱 저장소 `violin-sheets`의 곡 기록에 `bpm`·`meter`가 들어가요(메트로놈 앱이 읽고 씀). 녹음은 `vm-recordings` 저장소에 따로 있어요(악보 백업 파일에는 안 들어가니 중요한 녹음은 내려받아 두세요). 튜너 기준음과 메트로놈 설정은 `vm:`로 시작하는 기기 설정에 있어요.

## 알아둘 점

- 튜너는 마이크를 쓰므로 처음에 허락을 물어봐요. 조용한 곳에서 한 줄씩 켜 주세요.
- 메트로놈은 화면이 꺼지지 않게 해 두지만, 휴대폰 무음 스위치가 켜져 있으면(아이폰) 소리가 안 날 수 있어요.
